# Contributing to IntelliHire

Thanks for your interest in contributing!

## Getting started

1. Fork the repository and clone your fork.
2. Copy `.env.example` to `.env` and fill in the required values.
3. Start the stack with `docker-compose up`.

## Submitting changes

1. Create a branch for your change: `git checkout -b my-feature`.
2. Make your changes and commit them with a clear message.
3. Open a pull request against `main` describing what changed and why.

## Guidelines

- Keep PRs small and focused.
- Add or update tests where relevant.
- Follow the existing code style; pre-commit hooks are configured in `.pre-commit-config.yaml`.
- Update documentation (`docs/`, `README.md`) when your change affects usage.
